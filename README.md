# Menhir Web

Baptism shell of the Menhir Web supplier stack: **Next.js App Router on Vercel**.

Clickable Higgsfield-shaped studio. No models, no API, no billing. Generate writes a fake job into Library (this browser’s `localStorage`).

**Owned by Menhir Tech. This is the supplier surface — not a client product.** Reno 3.0 remains the first client supply.
